Stripe Checkout

Accept cards on a secure, Stripe-hosted payment page.

About this gateway

Stripe redirects your client to a secure payment page hosted by Stripe, then brings them back once they've paid. It's the quickest and safest way to accept cards, because Stripe handles all the sensitive card data for you.

Not sure which one to choose?

Stripe Checkout (recommended): Stripe hosts the payment page - it's the simplest to set up and the most secure, with no extra compliance work for you. Stripe.js: the card fields are embedded directly in SolidInvoice for a more seamless look, but you take on more PCI-compliance responsibility. If you're unsure, choose Stripe Checkout.
